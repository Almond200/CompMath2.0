Algebra

Quadratic formula
For ax2 + bx + c = 0 with a ≠ 0, the roots are (−b ± √(b2 − 4ac))/(2a).
Vieta’s formulas
The two roots of that quadratic have sum −b/a and product c/a.
Finite geometric series
The first n terms with initial term a and common ratio r sum to a(1 − rn)/(1 − r) if r ≠ 1. For r = 1, the sum is na.

Geometry

Pythagorean theorem
In a right triangle with legs a and b and hypotenuse c, a2 + b2 = c2.
Law of cosines
If angle C lies between sides a and b, the opposite side satisfies c2 = a2 + b2 − 2ab cos C.
Heron’s formula
For side lengths a, b, and c, set s = (a + b + c)/2. The area is √(s(s − a)(s − b)(s − c)).

Number theory

Euclidean algorithm
For integers a ≥ b > 0, replace (a, b) with (b, the remainder of a divided by b). When the second entry is zero, the first is the greatest common divisor.
Counting positive divisors
If a positive integer factors as p1e1 ⋯ pkek with distinct primes, the number of positive divisors is (e1 + 1) ⋯ (ek + 1).
Fermat’s little theorem
If p is prime and does not divide a, then ap−1 ≡ 1 (mod p).

Combinatorics

Combinations
For 0 ≤ k ≤ n, the number of ways to choose k items from n distinct items is n!/(k!(n − k)!).
Inclusion–exclusion for two sets
Add the sizes of the two sets and subtract the size of their intersection. The elements in the intersection were counted twice.
Complementary probability
The probability that an event occurs equals 1 minus the probability that it does not occur.
