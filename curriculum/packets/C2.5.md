# Authoring packet: C2.5, Counting with Recurrence Relations

`combinatorics-2/C2.5` · Year 2 anchor (Lesson 19; not yet reviewed for structure) · Stage S1 (draft for review)

## 1. Narrative arc

Some counts are hopeless to list, yet easy to build from smaller cases. The chapter's question is: *what is the smallest amount of information about a partial object that tells me how it can continue?*

It starts with tilings, where the last tile splits the count into disjoint, reversible cases, and so explains why a recurrence is correct, not just plausible. Strings with a forbidden pattern then show that a single total can lose information: the last symbol or the last run has to be remembered, and this is the idea of a *state*.

Circular arrangements add a boundary condition. Walks on graphs make the state a vertex. Lattice paths are the special case where the state is a point. The chapter ends with problems where the learner must propose the state before seeing any recurrence (spec teaching sequence).

## 2. Learning objectives

1. Derive a recurrence from a first-step or last-step decomposition and prove it counts each object once.
2. Choose initial values, including the empty configuration, and check them against small cases.
3. Recognise when one sequence is not enough, and define sufficient states (last symbol, run length, endpoint, vertex).
4. Handle circular boundary conditions by tracking the starting state.
5. Compute counts by tabulating states, not by solving the recurrence; closed forms are optional (A2.10).
