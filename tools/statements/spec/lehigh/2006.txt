=== 30

=== 31

=== 32

=== 33

a. $B$ has exactly $8$ elements;

b. If $x\in S$ is even, then $x$ is in $B$ if and only if $x/2$ is in $B$;

c. If $y\in S$ is odd, then $y$ is in $B$ if and only if $(y+15)/2$ is in $B$.

Which elements of $S$ cannot be part of a special subset?
