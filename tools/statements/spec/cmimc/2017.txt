=== computer-science-4
How many complete directed graphs with vertex set $V=\{1,2,3,4,5,6\}$ contain no $3$-cycles?

A graph is directed if all edges have a direction (e.g. from $u$ to $v$ rather than between $u$ and $v$), and complete if every pair of vertices has an edge between them. Further, a $3$-cycle in a directed graph is a triple $(u,v,w)$ of vertices such that there are edges from $u$ to $v$, $v$ to $w$, and $w$ to $u$.
=== computer-science-5
Given a list $A$ of $n$ real numbers, the following algorithm, known as insertion sort, sorts the elements of $A$ from least to greatest.

$IS(A)$:
• For $i=0,\dots,n-1$:
• • $j\leftarrow i$
• • While $j>0$ and $A[j-1]>A[j]$:
• • • Swap $A[j],A[j-1]$
• • • $j\leftarrow j-1$
• Return $A$.

As $A$ ranges over all permutations of $\{1,2,\dots,n\}$, let $f(n)$ denote the expected number of comparisons (i.e., checking which of two elements is greater) that need to be made when sorting $A$ with insertion sort. Evaluate $f(13)-f(12)$.

• • If balls $i-1$ and $i$ have the same color:
• • • $j\leftarrow$ smallest index greater than $i$ for which balls $i-1$ and $j$ have different colors
• • • Swap balls $i$ and $j$.
