# Verified short-answer keys

`js/data/problems/answer-keys-short.js` contains answers verified against official keys, worked solutions, or independent calculations. The `sources` map records the official solution URL or the problem paper used for independent verification. The paper ID is the problem slug without its final problem number. The import matches numbered questions in the source PDFs to the app’s slugs and checks against local statements. Plain numeric answers can be extracted from the labeled answer in a PDF. Stacked fractions, radicals, and questions with more than one answer need particular care because PDF text extraction can drop signs, fraction bars, and exponents.

Each entry contains an `answers` array of fully correct submissions. Its default format is a single real value. Use `format: "set"` for an unordered list of values, `"sequence"` for a list that must follow a specified order, `"tuple"` for one parenthesized ordered tuple, and `"tuple-set"` for an unordered list of ordered tuples. Put a complete list in one string, such as `["4, 6"]`. For questions with distinct accepted answers, list each acceptable answer separately and set `alternatives: true`. Practice accepts one or more answers as long as each is correct. Use commas between answers and a semicolon between complete ordered lists. A question asking for all values still requires a complete answer. For an ordered tuple that mixes numbers and a letter, give each component its own notation. The 1998 HMMT February Geometry #10 key accepts `27, H, 208` with optional parentheses and an optional feet unit on the distance.

Use plain math expressions in the keys. The answer field accepts fractions, mixed numbers such as `-1 1/2`, `sqrt(3)`, `cbrt(2)`, `pi`, powers, factorials, binomial coefficients such as `choose(2019,3)`, `ln`, and the `sin`, `cos`, and `tan` functions. Separate entries with a comma. Spaces are optional. Exact rational keys require exact equality. The checker reduces fractions, proves common root and trigonometric identities, and cancels equal terms and nonzero factors before evaluation. A small numerical tolerance still applies to keys that evaluate numerically. Questions with an unverified key or an unsupported answer form stay available for self-check. Saved self-check sets keep their existing marks.

Set `external: true` when the problem is read from the original paper and the app has a verified key. Practice links to the paper and grades the response from the key.

Use `"percent"` when the official answer is expressed as a percentage. The player can include or omit the percent symbol. Use `"text"` for short answers such as a day of the week or digits in a specified base. List acceptable forms explicitly. Text matching ignores case and extra spaces.

Use `"complex"` for one complex number and `"complex-set"` for all complex numbers. The player can use `i`, common arithmetic operations, integer powers, and `sqrt(z)` for the principal square root. Integer powers of `i` use its four-value cycle. Other complex powers accept integer exponents from −64 to 64. Real and imaginary components are compared separately. For example, `0, ±i*sqrt(6)` stands for all three values in 2024 HMMT February Algebra and Number Theory #9.

Use `fib(n)` for an exact Fibonacci number with \(F_0=0\) and \(F_1=1\). A key can set `notation: "fibonacci"` to accept `F_n` in the context of that problem. The published answer to 2020 CMIMC Combinatorics and Computer Science #8 can be entered as `(100, F_104+1223)` or `(100, fib(104)+1223)`. [Official solutions](https://github.com/howard36/cmimc-official/blob/master/public/assets/docs/past-tests/2020_CCS_S.pdf)

Use `"interval"` for a real interval or union. The checker accepts bracket notation and inequalities such as `[38,88)` and `38 <= x < 88`. An unbounded endpoint can use `inf` or `infinity`. Separate disjoint intervals with `U` or `or`. Open and closed endpoints affect the grade.

Use `"polynomial"` with the variable in `notation`. The checker compares exact rational coefficients through degree 32. For example, `n(n+5)-3` and `n^2+5n-3` both work for 2006 Lehigh #30. Use `notation: "ratio"` on a single real value when the prompt asks for a ratio. Students can enter `4:6` or `2/3` for the same ratio.

Practice saves and typesets symbolic entries such as `y=2x` and `A_{104}/z`. The answer key's format still determines whether the entry earns credit.

Use `"rational-function"` with a single variable in `notation` for a quotient of polynomials. The checker compares the cross-products by exact coefficients, so it compares formulas on their common domain. The 2009 Duke Math Meet #2 key accepts `2/n`, `2*n^-1`, and `1/n+1/n`.

Use `"exponential-function"` for a formula in an integer variable with constant rational bases, such as `2^(n-1)` or `3^n-(n+1)*2^n+n*(n+1)/2`. The checker groups terms with the same base and compares exact polynomial coefficients after cross-multiplying any fractions. In the 2011 HMMT grid problem, `2^n/2` and `(1/2)^(1-n)` both earn credit. [Official solutions](https://hmmt-archive.s3.amazonaws.com/tournaments/2011/feb/algcomb/solutions.pdf)

Use `"symbolic-rational"` for a quotient of polynomials with multiple named variables or large exponents. The `notation` string lists the variables with commas, for example `"a,b"`. The 2009 HMMT February Algebra #7 key accepts both `x^9900*((1+x^100)/2)^2` and its expansion. Use `"symbolic-radical"` for a positive square root of a rational expression, with an optional positive rational scale factor. For 2005 HMMT February Geometry #7, the area vector has components of magnitudes \(x,y,z\), giving `sqrt(x^2+y^2+z^2)`. [2009 Algebra solutions](https://hmmt-archive.s3.amazonaws.com/tournaments/2009/feb/alg/solutions.pdf) · [2005 Geometry solutions](https://hmmt-archive.s3.amazonaws.com/tournaments/2005/feb/geo/solutions.pdf)

Use `notation: "angle"` for keys in radians that also accept an explicit degree unit. The 2025 SMT Algebra #8 key accepts `29pi/12`, `435°`, and `435 deg`. For the fixed units recorded in the key, students can include the unit or enter the number alone. This includes `9 points` in 2009 Duke Math Meet #3, `145 inches` in 2013 BmMT #14, and `184 sq in` in 2009 Lehigh #27.

Use `notation: "repeating-decimal"` when the published answer includes a recurring decimal. For 2019 BMT Discrete Math #2, `0.(18)` and `0.\overline{18}` both represent exactly `2/11`. A finite decimal is compared by its exact value. [Official solutions](https://berkeley.mt/archives/bmt-2019/discrete-solutions.pdf)

Use `format: "tuple", notation: "polar"` for a radius and angle. The checker accepts coterminal angles, including degrees with `°` or `deg`. Use `notation: "profit"` on a signed real key when the question asks for a gain or loss. Both `-40` and `40 loss` express the same loss.

Use `format: "percent", notation: "percent-change"` when a question asks for the direction of a percentage change. For a decrease, `-9%`, `decreases by 9%`, and `9% decrease` all express the same answer.

Use `format: "numeral"` for a value whose digit representation matters, and `format: "sequence"` when several numerals must be entered in a specific order. Set `notation` to the base, such as `"base-2"`, `"base-3"`, `"base-8"`, or `"base-phi"`. The same parser accepts an optional typed or Unicode subscript or a label such as `(base 2)`. Leading zeros and trailing fractional zeros preserve the value, and the preview displays the digits entered. The base-\(\phi\) key for 2019 CHMMC #10 accepts `10000.00010` because \(\phi^4+\phi^{-4}=7\). One power cannot give 7, and with two distinct exponents the largest must be 4 since \(\phi^3+\phi^2<7<\phi^5\). [CHMMC solutions](https://www.caltechmathmeet.org/_files/ugd/006423_51e4bf40e50b4aa5bd2a5fbc06da8009.pdf)

Every typed Practice answer uses the same Math keypad. AIME still grades integers from 0 through 999, including expressions that evaluate to those values and entries with leading zeros such as `007`.

Read the submission instruction in the problem and inspect the typeset official answer when the PDF extraction is ambiguous. Check what a subscript denotes before selecting a format. A Fibonacci number, a digit string in a specified base, and an indexed variable require different handling. Record any notation that still needs a verifier with the problem number and source.

If a key and its solution disagree, first match the question to the original sitting. Check the PDF, any organizer correction, and an independent calculation before changing the accepted value. Record the published and corrected answers with the source. Log unusually large exact values along with the relevant limits of the grader so their support can be decided from the actual problem.

The `voided` map records questions removed from grading, along with the reason. Start each notice with **Organizer ruling.** when the organizers withdrew the question or neutralized it in scoring. Use **Practice ruling.** when the app voids the question based on the printed prompt or the published solution. The same notice appears during the set and in review. When an archive contains a withdrawn original and a published replacement, match the displayed prompt to the paper before applying the withdrawal.

| Source finding | Practice behavior |
| --- | --- |
| The organizer withdrew the question | Void it and show the reason. |
| The organizer accepted multiple submissions | Give full credit for any nonempty subset of accepted alternatives. |
| A published key is incorrect | Verify the correct answer independently, use it to grade the prompt shown, and explain the discrepancy in Practice review. |
| The printed prompt is underdetermined | Use self-check while the ambiguity remains, or void the problem when the available evidence calls for it. |
| The requested result is undefined or impractical to compute by hand under contest conditions | Void the problem in Practice and explain why. |
| The grader lacks a valid answer format | Keep self-check and document the needed format. |

### Short-answer audit procedure

Before treating a round as lacking solutions, check the tournament archive and any organizer or host-institution mirror. Confirm the year, round, and exact prompt before using a key. Before starting the multiple-choice pass, reconcile every indexed short-answer problem with its paper and question number. Recheck the rendered source when an answer spans pages, is absent from its box, or disagrees with the worked solution. Search the official papers for corrections, withdrawals, accepted alternatives, and references to earlier versions. Verify the requested units, ordering, number of values, and any domain constraints against the prompt. For papers without published answers, record the independent solution and how its result was cross-checked. Confirm that Practice accepts the verified forms, rejects wrong values, and handles voided questions correctly during submission and review. Record unresolved cases individually.

- Match the version displayed in the app to the organizer’s correction. Check duplicate questions across rounds for the same wording and choices before propagating a ruling.
- Check whether rational simplification hides excluded inputs, whether an approximation respects the stated precision, and whether the prompt requires a specific form such as a factorization, numeral, or angle unit.
- For probability and counting, check independence, uniformity, distinguishability, ordering, rotations, and reflections. For algebra and geometry, check repeated roots, zero terms, empty sets, tangency choices, nonconvex cases, and points on extensions where the source permits them.
- Reopen saved and completed sets after grading updates. Confirm that saved responses and self-check marks persist, that a withdrawal is explained, and that score treatment follows the organizer’s ruling where the app models contest scoring.
